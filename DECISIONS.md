# Design Decisions

I changed the names because they did not help me understand what was going on when I first started the program. 
I knew if I had difficulty others would as well, so I chose names that better represented what was going on in the program.

Secondly, I chose to use list comprehension instead of a for loop for calculations so that it could be easier to maintain. 
The first option used took too many lines to compute something that could be done in one line. 
Then if changes want to be made it will be easier to do that.

Lastly, I added docstrings so that someone who wasn't assigned this project can still understand what each function was intended to perform.
